# Лабораторна 1. CI/CD для PHP

![PHP CI](https://github.com/Danyleichuk-Vladyslav/php-lab/actions/workflows/php-ci.yml/badge.svg)

Навчальний проєкт: клас Calculator, перевірка оформлення Laravel Pint і тести PHPUnit.

Можливості:

- додавання двох цілих чисел;
- віднімання двох цілих чисел;
- перевірка оформлення коду;
- модульні тести.

## Запуск тестів

```bash
composer install
./vendor/bin/phpunit tests/Unit
```
